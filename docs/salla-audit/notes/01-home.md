# 01 — الرئيسية (ملخص المتجر)

- **المسار:** الرئيسية `/` (تبويب «ملخص المتجر»). **النسخة:** الجديدة.

## المكونات
| المكون | ما يمكن فعله |
|---|---|
| ترحيب باسم المستخدم | — |
| بانر ترويجي (مثلًا حملة إعلانات سلة «أطلق حملتك ويرجع لك مبلغ» بشروط: إطلاق قبل تاريخ، تشغيل 7 أيام، صرف حد أدنى) | زر «أطلق حملتك» → إعلانات سلة، رابط الشروط والأحكام، زر إغلاق (X) |
| تنقل سريع | اختصارات مفضّلة بنجمة: المحفظة والفواتير، تصميم المتجر، الإعلانات، التقارير، متجر التطبيقات، الموظفين، الأدوار الوظيفية، صفحات الهبوط، أداء المتجر. يمكن تثبيت/إزالة الاختصار بالنجمة |
| ملخص الشهر | الزيارات، صافي المبيعات، عدد الطلبات + رسم بياني يومي/شهري، زر «استعرض كل التقارير» → `/reports/performance` |
| أضف هدفًا | زر «أضف هدف الشهر» (لم يُحفظ) |
| الزيارات في آخر ساعة | رسم مباشر + تحديث؛ ظهر «لا توجد بيانات بعد» |
| أحدث الطلبات | جدول (رقم الطلب/عميل، السعر، تاريخ الطلب، الحالة) + سهم إلى `/orders` |
| السلات المتروكة | تنبيه «لديك N سلة متروكة هذا الشهر بقيمة مبلغ» + زر «إضافة خصم» → `/marketing/carts/reminders`؛ جدول (العميل، السعر، المنتجات، الحالة) |
| سلة خطوة بخطوة | قوائم تشغيل تعليمية على يوتيوب (تأسيس المتجر، التسويق والنمو) |
| آخر تحديثات المنصة | مقالات/نشرات أخبار سلة |
| مجتمع سلة | تبويبات: تسويق ونمو، محتاج فزعتكم، تجارب التجار (منشورات من community.salla.com) |
| أكاديمية سلة | دورات |

## رأي
- **جيد:** نظرة سريعة مفيدة (مبيعات/طلبات/سلات متروكة) مع إجراء مباشر (إضافة خصم للسلات المتروكة).
- **صعب:** مزدحمة بمحتوى تسويقي وتعليمي ومجتمعي على حساب البيانات التشغيلية؛ لا تخصيص لترتيب البطاقات سوى «تنقل سريع».
