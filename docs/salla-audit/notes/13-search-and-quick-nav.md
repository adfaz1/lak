# 13 — البحث الشامل والتنقل السريع

**النسخة:** الجديدة.

| الأداة | الوصول | السلوك |
|---|---|---|
| البحث الشامل | أيقونة العدسة في الشريط العلوي | نافذة «ابحث في الصفحات أو الإعدادات»؛ النتائج مقسمة إلى **صفحات** (مع مسارها، مثل «الكوبونات — التسويق») و**إعدادات** (مثل «تفعيل الكوبونات»، «تفعيل تعدد الكوبونات»)؛ تنقل بالأسهم وEnter. **لا يبحث في البيانات** (طلبات/عملاء/منتجات) — لذلك بحث مستقل داخل كل صفحة |
| قائمة «الكل» | زر «الكل» | Mega-menu بكل الأقسام (انظر 00) |
| الشريط العلوي | دائم | الرئيسية، الطلبات، المنتجات، التسويق، المتجر وقنوات البيع، التقارير — كل منها قائمة منسدلة بالعناصر الفرعية |
| الشريط الفرعي | أسفل الشريط العلوي | تبويبات القسم الحالي + «المزيد ⋯» |
| تنقل سريع | الرئيسية | اختصارات مفضلة بالنجمة |
| أيقونة التطبيقات | الشريط العلوي | تطبيقات مثبتة مختارة + «مشاهدة كل التطبيقات» |
| الإشعارات | أيقونة الجرس | (لم تُفتح بالتفصيل) |
| مشمر (AI) | زر «مشمر» تحت الشريط | مساعد محادثة جانبي |
| قائمة الحساب | يسار الشريط | الباقة والاشتراكات، المقترحات، تفضيلات الإشعارات، **العودة للوحة التحكم السابقة**، English (Beta)، الملف الشخصي، الخروج |

## ملاحظات تقنية أثناء الفحص
- إصدار الواجهة: `@salla.sa/dashboard v0.691.0`.
- **التحميل المباشر للروابط متقطع:** عدة صفحات (الرئيسية، أداء المتجر، الإحالة، عمليات الدفع، التوثيق، الأتمتة) ظهرت فارغة تمامًا عند فتح الرابط مباشرة، وعملت عند التنقل الداخلي عبر القائمة. لم تظهر أخطاء في الكونسول (فقط تحذير متكرر «Failed to parse mobile headers»).
- نوافذ منبثقة متكررة: فيديو ترويجي عائم (برنامج الإحالة) في أسفل الشاشة، وجولات تعريفية.

## رأي
- **جيد:** بحث يشمل الإعدادات بدقة؛ تنقل ثلاثي المستوى واضح.
- **صعب:** لا بحث شامل للبيانات؛ الروابط المباشرة غير موثوقة.
