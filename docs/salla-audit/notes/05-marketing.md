# 05 — التسويق (والأتمتة)

**النسخة:** الجديدة. معظم الأدوات تحمل شارة «متاحة في باقتك» (الباقة الحالية: برو).

| الخدمة | المسار | ما يمكن فعله | ملاحظات/شروط |
|---|---|---|---|
| إعلانات سلة | التسويق > إعلانات سلة `/marketing/ads/dashboard` | لوحة: إنشاء إعلان، منصات (سناب، تيك توك، جوجل، ميتا، يوتيوب)، مؤشرات (الظهور، تكلفة النقرة، النقرات، المصروفات) برسم زمني، **رصيد المتجر** («الرصيد منخفض» + «شحن رصيد»)، توزيع النفقات حسب المنصة، أحدث الحملات | بانر «انتقل إلى الإصدار 2.0» — أي أن الإعلانات نفسها لها إصداران. التكلفة: رصيد مدفوع مسبقًا؛ عرض ترويجي على الرئيسية (استرجاع رصيد بشروط + خدمة تعزيز مدفوعة) |
| أدوات التتبع | التسويق > أدوات التتبع `/marketing/integration-tools/{snapchat…}` | تبويبات: سناب شات، تيك توك، ميتا، جوجل، إكس، منصات أخرى، كتالوج المنتجات. لكل منصة: حالة الربط، إلغاء الربط، معرّف البكسل، CAPI (تتبع من الخادم)، رابط كتالوج سري للصق في مدير الكتالوج | (لم تُنسخ المعرفات) تحذير صريح بعدم مشاركة رابط الكتالوج |
| السلات المتروكة | التسويق > السلات المتروكة `/marketing/carts` | مؤشرات الفترة (الإجمالي، نسبة الاستعادة، متوسط السلة مع المقارنة الشهرية) + «عرض التقرير كامل»، تصفية، **تصدير السلات**، جدول (العميل، المنتجات، الإجمالي، آخر تحديث، مرحلة الشراء، الحالة) | — |
| تذكيرات السلات المتروكة | `/marketing/carts/reminders` | «تذكير جديد»؛ جدول (الاسم، مدة الترك، قناة الإرسال، الخصم، إجراءات)؛ موجود تذكير افتراضي بعد ساعة بلا خصم | ترويج لتطبيق «صوت» (مكالمات آلية) — تطبيق إضافي |
| الكوبونات | التسويق > الكوبونات `/marketing/coupons` | «كوبون جديد»، تصفية، **تصدير الكوبونات**، تبويبات الحالة (الكل/مفعل/معطل/منتهي/مجدول/مكتمل الاستخدام)، جدول (الكوبون، الخصم، البداية، الانتهاء، الحالة، إجراءات) | شريط فرعي: الكوبونات، العروض الترويجية، الكاش باك، الإعدادات (رابط «الإعدادات» يشير لنفس صفحة الكوبونات — خلل تنقل محتمل) |
| العروض الترويجية | `/marketing/offers` → `/marketing/offers/new` | قائمة عروض (فئة/نوع/تواريخ/حالة مع مفتاح تفعيل، تعديل، إحصاءات، حذف) + طرق عرض. **أنواع العرض:** اشترِ واحصل على آخر (مقترحات ذكية)، خصم منتج، جدول الخصومات (كميات)، سعر ثابت، عروض السلة (مستويات)، عرض فئات العملاء؛ **عروض الدفع:** كاش باك، عرض بنكي (بطاقات محددة) | توقف الفحص عند شاشة اختيار النوع |
| الكاش باك | `/marketing/offers/cashback` | «عرض جديد» + جدول عروض الكاش باك | يُضاف لرصيد محفظة العميل بعد الطلب |
| المؤثرين | `/marketing/influencers` | سوق مؤثرين: مقترحون/الأكثر طلبًا/المنضمون حديثًا، تصنيفات الاهتمام، أعداد المتابعين لكل منصة، تقييمات، شارة «مؤثر مميز» | تكلفة تحدد لكل مؤثر (غير ظاهرة في القائمة) |
| الحملات التسويقية | `/marketing/campaign/retargeting` | «اضافة حمله» (SMS وإشعارات التطبيق)، تصفية، سجل حملات سابقة مع حالة الإرسال، تبويب «مدير الأحداث» | «العدد الحالي» = رصيد/حد رسائل؛ الرسائل تتطلب رصيد SMS |
| محفظة العميل | `/marketing/customer_wallet` | مؤشرات (المضافة، المستخدمة، المنتهية، المتبقية)، سجل العمليات (العميل، التفاصيل، النوع، رقم الطلب، الانتهاء) + تصفية + تصدير | — |
| التسويق بالعمولة | `/marketing/affiliate` → `/marketing/affiliates` | «فرصة تسويقية جديدة»، نظام موحد تديره سلة (دفع المستحقات ومتابعة الأداء)، مؤشرات (مبيعات/طلبات/عمولات)، تبويبات (مفعل/معطل/منتهي/متوقف بسبب مخالفة) | — |
| تحسين محركات البحث | `/marketing/seo/homepage` → `/marketing/seo/seo-setting` | عنوان/وصف عربي وإنجليزي بعدادات أحرف، كلمات مفتاحية (حتى 10)، sitemap.xml، معاينة جوجل | ⚠️ الوصف العربي الحالي **278/160** حرفًا (تجاوز الحد دون منع) |
| برنامج الولاء | `/marketing/loyalty` → `/loyalty/points` | تبويبات: النقاط، المكافآت، التذكيرات؛ طرق كسب النقاط + عددها | «برنامج الولاء غير مفعّل» + زر «تفعيل البرنامج» (لم يُضغط) |
| نظام الإهداء | `/marketing/gift` | إهداء المنتجات الرقمية والملموسة، تخصيص نصوص وبطاقات الإهداء | صفحة تعريفية/«اعرف أكثر» |
| تذكيرات إعادة الشراء | `/marketing/reorder-reminders` | «تذكير جديد»؛ جدول (التذكير، المنتج، الخصم، المدة منذ آخر شراء) | يحمّل ببطء (فارغ في المحاولة الأولى) |
| برنامج الإحالة | الأدوات المساعدة > برنامج الإحالة `/marketing/referrals` | — | ❌ **تعذّر:** الصفحة تبقى فارغة تمامًا في 3 محاولات (لا نص ولا أخطاء في الكونسول) |
| الأتمتة (سير العمل) | الأدوات المساعدة > الأتمتة `/marketing/flows` | مؤشرات (إجمالي/نشطة/مسودة/تشغيلات اليوم)، «مسار عمل جديد»، «إنشاء سير عمل». **القوالب** `/marketing/flows/templates`: من سلة/قوالبي/المجتمع، فرز (الأكثر استخدامًا/الأحدث/الرائج)، أهداف (استرجاع المبيعات، تحويل الزوار، عودة العميل، رفع قيمة الطلب، مكافأة أفضل العملاء، طمأنة العميل، توفير الوقت)، أمثلة: عروض المناسبات/عيد الميلاد، إدارة المخزون تلقائيًا، تقرير دوري بالبريد، شكر العميل، إكمال الدفع المتعثر. نظام «مستوى صانع القوالب» (مبتدئ → صاعد بعد 10 متاجر) | شارة «جديد»؛ لم يُفتح المحرر لتجنب إنشاء مسودة |

## رأي
- **جيد:** أدوات تسويق داخلية متكاملة (عروض متعددة الأنواع، كاش باك، محفظة، ولاء، عمولة، مؤثرين، إعلانات مدارة)؛ الأتمتة الجديدة مع سوق قوالب مجتمعي ميزة قوية؛ التتبع يشمل CAPI.
- **صعب:** «الإعدادات» في شريط الكوبونات يعود لنفس الصفحة؛ برنامج الإحالة لا يعمل؛ بعض الصفحات تحتاج إعادة تحميل لتظهر (تحميل متقطع)؛ إعلانات سلة بإصدارين؛ تجاوز حدود SEO بلا تحقق.
